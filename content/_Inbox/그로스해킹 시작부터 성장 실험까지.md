## 1. 그로스 해킹 시작하기

그로스 해킹 = 성장실험 (핵심 지표 정의 -> 가설 수립 -> 실험 -> 분석 -> 개선)

###  1) 그로스 해킹 준비하기
1. 데이터 활용 업무 환경 구축 (데이터 수집)
2. 데이터 파이프라인 구축 (데이터 적재 및 가공)
3. 데이터 활용을 위한 역량과 문화 탑재 (역량 갖추기)
4. 성장 실험 (데이터 활용)

### 2) 데이터 기반 의사결정 문화
데이터 기반으로 업무를 진행하는 프로세스와 역량을 갖춰야함.

#### 그로스 팀의 업무 범위
- 핵심 지표 선정 및 관리

- 주제별 데이터 분석
- 데이터 추출 및 분석 요청 대응 (-> 우린 만들고 땡이니 대시보드를 잘 만들고, 사용설명서 + excel export 기능 필수~)
- 데이터 기반으로 일하는 문화 만들기

## 2. 데이터 파이프라인 구축 for 행동 로그 분석

### 1) 구축 전 필수 질문
- 어떤 데이터를 쌓을 것인가?
- 어떤 형태로 쌓을 것인가?
- 어디에 쌓을 것인가?
- 어떻게 꺼내볼 것인가?
- (이벤트 등 자유도 높은 데이터의 경우) 얼마나 쌓을 것인가?
### 2) 이벤트와 속성
행동 로그 설계의 핵심: 이벤트의 속성(property, parameters)을 어떤 수준으로 남길 것인가???????? (이거 개빡셈)

더욱 입체적인 인사이트 도출을 위해선 디테일한 이벤트 속성 + 사용자 속성 집계가 필요

### 3) 행동 로그 스키마 설계 -> 적재
"필요한 이벤트만 정확하게"

스키마를 설계하는 것 뿐 아니라 실제 이벤트 값을 웹으로부터 받아오려면, 
GoogleTagManager와 같은 이벤트 태깅 툴로 이벤트를 관리해야 한다.

근데 login 전환, 구매 전환 등의 핵심적이면서도 정합성이 중요한 이벤트는
GTM에서 이중 삼중으로 트리거를 배치하여 태깅하는 것보단 개발자랑 협업하여 js코드를 삽입하는 것이 ~~내가 편함~~ 효과적임.
